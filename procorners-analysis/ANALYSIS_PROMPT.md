# برومبت رئيسي: تحليل وتحسين متجر «ركن التسوق» عبر أدوات MCP (AI Engine)

> **طريقة الاستخدام:** الصق كل ما تحت الخط في **Claude Code على جهازك** (حيث خادم `procorners`
> متصل ✓). سيتولّى تنفيذ التحليل العميق وإنتاج مسودّات «قبل/بعد» للموافقة — **دون أي كتابة على
> المتجر إلا بموافقتك**.

---

أنت محلّل ومحسّن لمتجر WordPress/WooCommerce «ركن التسوق» عبر أدوات MCP من خادم `procorners`
(إضافة AI Engine). نفّذ المهمة بالمراحل التالية، وتوقّف للموافقة قبل أي كتابة.

## القواعد (إلزامية)
- **لا** تستخدم أي أداة حذف أو مدمّرة: `wp_delete_post`, `wp_delete_post_meta`, `wp_delete_term`,
  `wp_delete_comment`, `wp_delete_media`, `wp_update_user`.
- **لا** تكتب أي تغيير (`wp_update_*`, `wp_create_*`, `wp_add_post_terms`, `mwai_image`,
  `wp_set_featured_image`) إلا بعد أن أوافق صراحةً على الدفعة.
- قبل أي كتابة: اعرض «قبل/بعد»، واحفظ القيمة الحالية في جدول تراجع.
- إن فشلت أي أداة، استدعِ `mcp_ping` للتحقق من الخادم قبل المتابعة.

## المرحلة 1 — تحقق واكتشاف
1. `mcp_ping` (تأكيد الاتصال واسم الموقع والوقت).
2. `wp_get_post_types` و`wp_get_taxonomies {post_type:"product"}` — أكّد وجود `product` وتصنيفاته.
3. عدّ: `wp_count_posts {post_type:"product"}`, `{post_type:"post"}`, `{post_type:"page"}`,
   وحاول `{post_type:"shop_order"}`؛ و`wp_count_terms {taxonomy:"product_cat"}` و`product_tag`؛ و`wp_count_media`.
4. `wp_list_plugins` — لاكتشاف إضافة السيو (Yoast / RankMath / AIOSEO / SEOPress)، الكاش، الأمان، السرعة.
5. اكتشف مفاتيح ميتا السيو: خذ منتجًا واحدًا عبر `wp_get_post_snapshot {ID, include:["meta"]}` وابحث عن
   `_yoast_wpseo_title/_yoast_wpseo_metadesc` أو `rank_math_title/rank_math_description` أو `_aioseo_*`.

## المرحلة 2 — سحب البيانات
- اسحب كل المنتجات عبر `wp_get_posts {post_type:"product", limit:100, offset:N}` بالترقيم حتى تنتهي.
- لعيّنة تمثيلية (≥15 منتجًا متنوّعة التصنيفات/الحالات)، اسحب `wp_get_post_snapshot {ID,
  include:["meta","terms","thumbnail"]}` لقراءة: `_price`, `_regular_price`, `_sale_price`, `_sku`,
  `_stock`, `_stock_status`, الوصف القصير/الطويل، التصنيفات، الصورة البارزة، وميتا السيو.
- `wp_get_terms {taxonomy:"product_cat", limit:100}` — التصنيفات (الاسم، العدد، الأب، الوصف).
- `wp_get_comments {status:"hold"}` و`wp_get_media` (عيّنة) لفحص النظافة والـ alt.

## المرحلة 3 — التحليل العميق (أربعة محاور)
لكل بند: حدّد (الخطورة، الأثر، الجهد، المحور). دوّن أمثلة فعلية بالـ ID والعنوان.

**1) SEO والمحتوى:** عناوين/أوصاف ميتا مفقودة أو مكرّرة أو خارج الطول (عنوان ≤60، وصف ≤155 حرفًا)؛
محتوى رقيق؛ slugs؛ نص بديل (alt) ناقص للصور؛ كلمات مفتاحية عربية.
**2) المنتجات/الكتالوج:** حقول ناقصة (سعر/SKU/صورة/وصف/تصنيف/مخزون)؛ منتجات يتيمة بلا تصنيف؛
تصنيفات فارغة أو متداخلة؛ سعر صفر؛ منشور وخارج المخزون؛ عناوين/أوصاف ضعيفة.
**3) المبيعات/التحويل:** إن توفّرت بيانات `shop_order`، استخرج الاتجاه و AOV والأكثر/الأقل مبيعًا؛
وإلا وثّق القيد واقترح مؤشرات بديلة.
**4) الأداء/الأمان/الصحة:** الإضافات (عدد/تكرار وظائف/قِدم)؛ كشف مستخدمين عبر `wp_get_users`؛
خيارات مهمة عبر `wp_get_option` (مثل `blog_public`, `users_can_register`)؛ تعليقات سبام؛ وسائط غير مستخدمة.

## المرحلة 4 — المخرجات
1. **تقرير أولويات** (جدول مرتّب بالأثر×الجهد) يغطّي المحاور الأربعة.
2. **مسودّات «قبل/بعد»** لأول دفعة (≈10 منتجات): عنوان محسّن، وصف عربي محسّن للسيو والتحويل،
   عنوان ميتا (≤60)، وصف ميتا (≤155)، اقتراح تصنيف/وسوم، ونص بديل (alt) مقترح للصور (استعن بـ
   `mwai_vision` لوصف الصورة عند الحاجة).
3. اعرض الدفعة واطلب موافقتي. **عند الموافقة فقط** طبّق عبر `wp_update_post` (العنوان/الوصف)،
   `wp_update_post_meta` (ميتا السيو/السعر/SKU)، `wp_update_media` (alt)، `wp_add_post_terms {append:true}`
   (تصنيفات)، مع حفظ القيم السابقة في جدول تراجع، ثم تحقّق بإعادة `wp_get_post_snapshot`.

ابدأ بالمرحلة 1 الآن واعرض عليّ نتائج الاكتشاف.
