# عُدّة تحليل متجر «ركن التسوق» عبر MCP

أدوات جاهزة لتحليل وتحسين متجر WordPress/WooCommerce على `procorners.com`
الذي يعرّض خادم MCP عبر إضافة **AI Engine**.

> **الحالة:** خادم الموقع يعمل ✓ (أُثبت الاتصال محليًا). الناقص فقط هو **فتح الوصول الشبكي**
> من بيئة Claude Code على الويب إلى `procorners.com` (المرحلة 0 أدناه). بمجرد فتحه، كل شيء
> يعمل بأمر واحد.

---

## المرحلة 0 — فتح الوصول (إجراء لمرة واحدة في إعدادات البيئة)

الوصول الشبكي الخارج في بيئة الويب محكوم بـ allowlist، و`procorners.com` محجوب حاليًا
(`x-deny-reason: host_not_allowed`). لتفعيله:

1. من إعدادات بيئة **Claude Code on the web**، اضبط **سياسة الشبكة** على «قائمة سماح مخصّصة»
   وأضِف النطاق: `procorners.com`
2. خزّن التوكن السرّي كمتغيّر بيئة في البيئة:
   - الاسم: `PROCORNERS_MCP_TOKEN`
   - القيمة: التوكن الخاص بك (لا تضعه في أي ملف داخل المستودع)
3. (اختياري لكن مفضّل) سجّل خادم MCP في إعداد البيئة لتظهر أدواته أصليًا كـ `mcp__procorners__*`:
   - النوع: `http`
   - الرابط: `https://procorners.com/wp-json/mcp/v1/http`
   - الترويسة: `Authorization: Bearer ${PROCORNERS_MCP_TOKEN}`
4. ابدأ جلسة جديدة.

التوثيق: https://code.claude.com/docs/en/claude-code-on-the-web

## الاستخدام

اضبط المتغيّرات ثم شغّل:

```bash
export PROCORNERS_MCP_TOKEN=********              # مطلوب
# export PROCORNERS_MCP_URL=...                   # اختياري، الافتراضي رابط procorners

# 1) اكتشاف: مصافحة + سرد كل الأدوات وتصنيفها (قراءة/كتابة)
python3 procorners-analysis/mcp_probe.py discover

# 2) سحب بيانات القراءة الشائعة (منتجات/مقالات/صفحات/طلبات...) إلى out/
python3 procorners-analysis/mcp_probe.py pull --limit 50

# 3) نداء أداة بعينها يدويًا (الاسم من مخرجات discover)
python3 procorners-analysis/mcp_probe.py call <tool_name> --args '{"per_page":5}' --save
```

المخرجات تُحفظ في `procorners-analysis/out/` (متجاهَلة في git لأنها قد تحوي بيانات المتجر).

## ماذا بعد؟ (التحليل والتحسين)

بعد نجاح `discover` و`pull`، يقرأ Claude البيانات المسحوبة ويُنتج:

- **تقرير أولويات** عبر المحاور الأربعة: SEO/المحتوى · المنتجات/الكتالوج · المبيعات/التحويل · الأداء/الأمان/الصحة.
- **مسودّات تعديلات «قبل/بعد»** (عناوين وأوصاف ميتا، أوصاف منتجات عربية محسّنة، تصنيفات/أسعار/عروض)
  — تُعرض للموافقة، ولا تُطبّق على المتجر إلا بعد موافقتك على كل دفعة.
- قبل أي كتابة فعلية: حفظ القيمة الحالية في سجلّ تغييرات للتراجع.

التفاصيل الكاملة للخطة في ملف الخطة المعتمد.
